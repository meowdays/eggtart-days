Eggtart Days update package

Upload/replace these files in the ROOT of your GitHub repository (the same level as the current index.html):
- index.html (replace existing)
- sw.js (new)
- manifest.webmanifest (replace existing)
- assets/ (logo.webp)
- icons/ (icon and favicon files)

Do not delete the repository or clear browser/site data. Existing routines, history and categories are stored in localStorage and are not cleared by this update.

After committing, open the installed app while online. It checks for updates and shows an “立即更新” prompt when a new version is ready. Tap it to reload into the new version.

Note: the icon shown inside the app is updated from assets/logo.webp. The Home Screen/desktop launcher icon may be cached separately by iOS/your operating system and might not change immediately.
